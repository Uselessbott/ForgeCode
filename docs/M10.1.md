# M10.1 — Bundled Alpine minirootfs + PRoot (offline)

## Status

M10.1 implementation complete in code and host/unit tests. **No emulator runtime verification on a supported device; only API 28 emulator available (below minSdk 31).** Runtime-only claims below are marked not runtime-verified.

## Scope

- Bundled offline Linux bootstrap: Alpine minirootfs extracted into app-private cache and spawned through PRoot.
- No network dependency for bootstrap in M10.1. `NETWORK_DOWNLOAD` is reserved for M11.
- Reuses existing M6/M7 PTY stack and M4/VFS validation patterns; no second PTY/archive extractor.
- PRoot is a compatibility environment, not a security sandbox.

## Proto / Contract (Layer 1)

`app/src/main/proto/forgebox.proto`:

- `LinuxBootstrapMode`: `BUNDLED_OFFLINE` (default for M10.1), `NETWORK_DOWNLOAD` (M11).
- `LinuxEnvInstallRequest`: `distro`, `bootstrap_mode` (default `BUNDLED_OFFLINE`), `source_path` (app-private path to bundled tar.gz copied by Kotlin).
- `LinuxEnvStatusResponse`: added `rootfs_present`, `proot_loader_present`, `shell_binary`.
- `LinuxShellSpawnRequest` unchanged: `project_id, cols, rows, env_json`.
- No agent/network proto messages added.

## Extraction / Validation (Layer 2)

- Rust extraction: `linux_env::extract_tar_gz_safe` in `rust/forgebox_core/src/linux_env.rs`.
- Validates archive entries: rejects traversal (`..`), absolute/root/prefix paths, and symlink/hardlink targets resolving outside destination rootfs.
- Directories/files created normally; symlinks/hardlinks allowed only when resolved target stays within extracted rootfs (Alpine minirootfs contains symlinks).
- No second extractor; extraction confined to app-private cache (`ForgeBox/Cache/linux/...`).
- Install flow: Kotlin copies bundled asset to app-private bootstrap path, Rust extracts to staging, swaps into `Cache/linux/alpine/rootfs`, writes state, emits progress events.

## PRoot Spawn (Layer 3)

`linux_shell_spawn` uses existing M6/M7 PTY stack (`runtime.rs` + `pty.rs`), not a new PTY.

Argv shape:

```text
<cache>/bin/proot --link2symlink -0 -r <rootfs> \
  -b /dev -b /proc -b /sys \
  -b <project_dir>:<project_dir> \
  -b <Cache/linux/tmp>:/tmp \
  -w <project_dir> /bin/sh -i
```

Environment:

- `HOME=/root`
- `TERM=xterm-256color`
- `PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin`
- `LANG=C.UTF-8`
- `TMPDIR=<Cache/linux/tmp>`
- `FORGEBOX_LINUX_ROOTFS=<rootfs>`
- `FORGEBOX_GUEST_CWD=<project_dir>`
- allowlisted user env overrides from `env_json`: `TERM`, `LANG`, `LC_ALL`, `LC_CTYPE`, `COLORTERM`

Guest CWD is the same absolute project directory path as outside, validated by VFS/project-root checks under `ForgeBox/Projects/<id>`.

## Kotlin/UI (Layer 4)

- `LinuxEnvViewModel` accepts bundled source provider; install copies asset to app-private bootstrap path then calls core with `BUNDLED_OFFLINE`.
- Install states: `NOT_INSTALLED -> EXTRACTING/INSTALLING -> READY/FAILED` via progress events.
- READY enables Linux shell option; Linux session spawn uses `LinuxShellSpawn` RPC through terminal controller.
- Uninstall removes `Cache/linux/alpine/` cache and resets state to `NOT_INSTALLED`.
- Package install convenience remains a PTY command. Offline network-required installs fail honestly; UI states "network required; M11 enables this".
- Mandatory UI text: "Linux compatibility environment. Not a security sandbox." and same-UID statement.

## Same-UID / Sandbox Statement

PRoot provides a Linux compatibility environment, not a security sandbox. Processes run with the app's normal Android UID. There is no separate Linux user isolation or security boundary; do not present PRoot as containment.
